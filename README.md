# EditorsTeam – Standard Structure

این نسخه از پروژه برای توسعه و به‌روزرسانی آسان بازسازی شده است.

## ساختار

- `index.html` فقط ساختار صفحه
- `assets/css/main.css` تمام استایل‌ها
- `assets/js/plan.js` داده‌ی برنامه آموزشی قابل استفاده مستقیم در مرورگر
- `assets/js/app.js` منطق اصلی برنامه
- `assets/js/splash.js` منطق صفحه شروع
- `assets/images/` لوگو، آیکون‌ها و تصاویر محتوایی
- `data/plan.json` نسخه خوانا و قابل ویرایش اطلاعات دوره
- `manifest.json` تنظیمات PWA
- `sw.js` کش و اجرای آفلاین

## روش به‌روزرسانی

1. برای تغییر ظاهر، فقط `assets/css/main.css` را ویرایش کنید.
2. برای تغییر عملکرد، `assets/js/app.js` را ویرایش کنید.
3. برای تغییر دوره‌ها، هر دو فایل `data/plan.json` و `assets/js/plan.js` را هماهنگ نگه دارید.
4. تصاویر جدید را در `assets/images/content/` قرار دهید و مسیرشان را در HTML وارد کنید.
5. بعد از تغییر فایل‌های اصلی، مقدار `CACHE_NAME` در `sw.js` را یک شماره افزایش دهید تا نسخه قدیمی کش نشود.

## اجرا

بهتر است پروژه با یک وب‌سرور محلی اجرا شود، نه با بازکردن مستقیم فایل:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید.


## پنل مدیریت GitHub

فایل `admin.html` پنل مستقل مدیریت پروژه‌ها و ادیتورهاست. نام مخزن، شاخه و توکن در خود پنل وارد می‌شوند. توکن عمداً داخل فایل‌های پروژه قرار نگرفته است. پنل فایل‌های `data/projects.json` و `data/editors.json` و تصاویر مربوطه را از طریق GitHub Contents API به‌روزرسانی می‌کند.

تصویر ادیتور باید JPG و دقیقاً مربع (نسبت ۱:۱) باشد.
