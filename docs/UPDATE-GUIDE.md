# راهنمای توسعه

## افزودن یا ویرایش آموزش
هر رکورد برنامه دارای این فیلدهاست: `id`, `day`, `week`, `date`, `course`, `level`, `icon`, `lesson`, `lessonCount`, `task`.
شناسه `id` باید یکتا باشد.

## افزودن پروژه جدید
کارت پروژه را در بخش پروژه‌های `index.html` اضافه کنید و نمایش آن را در تابع `openProject` داخل `assets/js/app.js` تعریف کنید.

## نکته امنیتی
اطلاعات ذخیره‌شده فعلی در `localStorage` مرورگر نگهداری می‌شوند و برای پنل مدیریتی چندکاربره یا اطلاعات حساس مناسب نیستند. برای مدیریت آنلاین واقعی باید API و احراز هویت سمت سرور اضافه شود.


## مدیریت ادیتورها
فایل `admin.html` را باز کنید. تغییرات در localStorage ذخیره می‌شوند. برای انتشار دائمی، خروجی JSON را با نام `data/editors.json` جایگزین کنید.
